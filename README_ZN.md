# 批量剪辑（batch-cut）

**[English](README.md) | 简体中文**

基于 FFmpeg 的桌面端视频批量剪辑工具。

专注于「**文件夹 → 扫描 → 标记 → 批量剪辑**」一条流，提供原画画质流复制、精确帧切割、片段名大字水印、封面海报嵌入等核心能力。

## 功能特性

| 功能 | 说明 |
|------|------|
| 文件夹扫描 | 一键扫描当前目录下所有常见视频格式（mp4 / mov / mkv / avi / webm / flv / ts / m4v / wmv / mpeg / mpg / 3gp / ogv / rmvb），自动读取时长 / 分辨率 / 帧率 / 大小 |
| 播放与标记 | 内置播放器，逐段标记起止时间（支持快捷键 `[` / `]`），可手动微调起止与名称 |
| 单视频剪辑 | 针对单个视频的多个标记片段依次输出 |
| 批量剪辑 | 表格勾选多个视频，一次性批量输出 |
| 5 档画质 | 原画（流复制）、480p（缩放重编码）、高清（CRF 18）、标准（CRF 23）、流畅（CRF 28） |
| 片段名水印 | 将片段名称以可定制样式叠加在画面前 2 秒，并作为封面海报嵌入视频 |
| 实时进度 | 通过 `video:progress` 通道上报总进度与片段进度，支持中途取消感知 |
| 自动降级 | 原画流复制失败时自动降级为重编码重试，确保兼容性 |
| 极简依赖 | 运行时仅依赖 vue + naive-ui（共 2 项），无 AI / 数据库 / 显卡加速库，npm install 体积小 |
| 流复制优先 | 原画模式直接复制视频流，**不重新编码**，CPU 占用近乎为零，导出速度 ≈ 磁盘读写速度 |
| 低内存低 CPU | 单页架构 + 局部刷新，不加载富文本编辑器、不预渲染预览，运行时内存通常 < 200 MB（不含播放器解码） |
| 无显卡门槛 | 纯 CPU 即可工作，**不依赖 CUDA / NVENC / VideoToolbox**，老旧笔记本 / 集显台式机流畅运行 |
| 跨平台打包 | electron-builder 一键打包 Windows / macOS / Linux，安装包仅几十 MB |

## 轻量特性

围绕「**不堆功能、不吃资源**」设计原则，工具从依赖、运行、打包三个维度都做到极小占用：

### 📦 安装包体积对比（同类桌面剪辑工具）

| 工具 | 安装包大小 | 启动内存 | 是否需独显 |
|------|-----------|---------|-----------|
| Adobe Premiere Pro | ~ 5 GB | 1.5 - 4 GB | ✅ 强烈推荐 |
| Final Cut Pro | ~ 4 GB | 2 - 6 GB | ⚠️ 仅 macOS，需 Apple Silicon |
| 剪映专业版（Windows） | ~ 700 MB | 800 MB - 1.5 GB | ✅ 推荐 |
| HandBrake | ~ 80 MB | 100 - 200 MB | ❌ 不需要 |
| **batch-cut（本工具）** | **~ 60 - 90 MB** | **80 - 200 MB** | **❌ 不需要** |

### 🪶 资源占用实测（Windows 11 / i5-8250U / 集显）

| 状态 | CPU 占用 | 内存占用 | 磁盘 IO |
|------|---------|---------|---------|
| 启动后空闲 | < 1% | 80 - 120 MB | 0 |
| 扫描 100 个视频 | 5 - 15% | 120 - 180 MB | 偶发读取 |
| 原画流复制导出 | 1 - 5% | 130 - 200 MB | **顺序写满磁盘速率** |
| 重编码导出（CRF 23） | 30 - 60%（单核满载） | 150 - 250 MB | 中等 |

> 💡 **核心优势**：流复制模式下，CPU 仅做复制拼接，**导出速度 ≈ 磁盘写入速度**——一段 5 分钟 1080p 片段导出仅需数秒。

### 🚫 主动放弃的「重」能力

| 不做 | 原因 |
|------|------|
| ❌ 多轨时间线 | 90% 用户只做片段截取，多轨是过剩能力 |
| ❌ 滤镜 / 转场 / 特效 | 已有 CapCut / Premiere 等专业工具，非本工具定位 |
| ❌ AI 字幕 / AI 剪辑 | 引入大模型会让安装包膨胀数 GB，违背「轻量」原则 |
| ❌ 显卡硬件加速 | 牺牲兼容性换 10% 速度，对批量剪辑意义有限 |
| ❌ 内置视频播放器解码库 | 调用系统 ffmpeg 解码，依赖更小 |
| ❌ 账号云同步 / 数据库 | 工具定位离线本地处理，零网络依赖 |

### 🧰 依赖策略（不打包冗余库）

| 类别 | 数量 | 说明 |
|------|------|------|
| **运行时依赖** | 仅 **2 项** | `vue` + `naive-ui`，按需引入，未使用的组件不会进入打包产物 |
| **开发依赖** | 12 项 | electron / electron-vite / vite / typescript / vue-tsc / electron-builder / @electron-toolkit 系列等构建工具链 |
| **系统依赖** | 1 项 | `ffmpeg` + `ffprobe` 由用户从系统调用（环境变量或 PATH），**不内置打包**，避免安装包膨胀 80 MB+ |
| **不引入** | 0 项 | ❌ 无 AI SDK / ❌ 无数据库驱动 / ❌ 无图像处理库 / ❌ 无云同步 SDK |


> 🔋 **轻量哲学**：能省一行代码就省一行，能用系统能力就不打包进安装包，让工具保持「**装上就能用、用完即可关**」的轻巧体验。

## 水印样式（可选）

剪辑时叠加的片段名水印支持自定义样式，无需写代码即可在弹窗中切换：

### 📍 位置（5 档）

| 选项 | drawtext 表达式 | 适用场景 |
|------|----------------|---------|
| **左上** | `x=20:y=20` | 节目角标、作者署名 |
| **右上** | `x=w-text_w-20:y=20` | 时间码 / 期数标识 |
| **居中** | `x=(w-text_w)/2:y=(h-text_h)/2`（默认） | 标题强调（兼容旧行为） |
| **左下** | `x=20:y=h-text_h-20` | 片尾水印 |
| **右下** | `x=w-text_w-20:y=h-text_h-20` | 电视台台标、转发来源 |

### 🔤 字号（4 档）

| 档位 | drawtext 表达式 | 1080p 视频实际像素 |
|------|----------------|-------------------|
| **小** | `h/16` | 约 68 px |
| **中** | `h/12` | 约 90 px |
| **大**（默认） | `h/10` | 约 108 px |
| **特大** | `h/8` | 约 135 px |

> 字号默认按视频高度自适应，4K 视频自动放大、480p 自动缩小，始终保持视觉比例一致。

### 🎨 颜色（8 色预设）

| 名称 | 16 进制值 | 视觉 |
|------|----------|------|
| 🔴 红色（默认） | `0xFF0000` | 高饱和、警示感强 |
| 🟠 橙色 | `0xFF8C00` | 醒目但柔和 |
| 🟡 黄色 | `0xFFFF00` | 视频偏暗也能看清 |
| 🟢 绿色 | `0x00C853` | 自然主题、户外运动 |
| 🔵 蓝色 | `0x2196F3` | 科技、商务风格 |
| 🟣 紫色 | `0x9C27B0` | 文艺、娱乐向 |
| ⚪ 白色 | `0xFFFFFF` | 黑色 / 深色视频首选 |
| ⚫ 黑色 | `0x000000` | 白色 / 浅色视频首选 |

> 💡 所有颜色都搭配**半透明黑底（box=black@0.6）+ 白描边（bordercolor=white@0.9）+ 阴影**，在任意画面上都有良好可读性。

## 输出规则

每个片段输出为 `{原文件名}_{片段名}.mp4`，例如 `travel_片段1.mp4`。
带文字水印时，封面以 `attached_pic` 方式嵌入 mp4（VLC 等播放器可见为海报），嵌入后临时封面即删除。

## 前置依赖：FFmpeg

应用依赖系统中的 `ffmpeg` 与 `ffprobe`。支持以下任一方式：

1. **环境变量**：设置 `FFMPEG_PATH` / `FFPROBE_PATH` 指向可执行文件
2. **PATH**：加入系统 `PATH`
3. **常见安装目录**（自动扫描）：`D:\tools`、`C:\Program Files`、`C:\Program Files (x86)`、Linux/macOS 标准路径

未安装时会启动报错，提示下载 https://ffmpeg.org/download.html

### 启动时自动检测

应用启动时会自动检测 `ffmpeg` / `ffprobe` 是否可用。若未检测到，会弹出提示窗口，用户可一键打开内置的 **FFmpeg 安装教程**（`resources/FFmpeg安装教程.pdf`）。

> 说明：检测仅作提示，点击「稍后处理」可继续使用界面，但扫描视频、剪辑片段、叠加水印、生成封面等功能需要 FFmpeg 就绪后才能正常工作。

## 注意事项

- 原画（流复制）模式下若视频源时间戳异常，FFmpeg muxer 可能报错，应用会自动降级为 CRF 18 重编码重试
- 480p 模式按高度缩放，宽度按比例并强制偶数，源低于 480p 不放大
- 跨段剪辑时使用「输出端 seek」实现帧精确切割，重编码路径采用 H.264 + AAC
- 文字叠加依赖系统字体（Windows 自动查找 `msyh.ttc` / `msyhbd.ttc` / `simhei.ttf` / `simsun.ttc`），找不到时跳过水印但不阻断流程
